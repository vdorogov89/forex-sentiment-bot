Еженедельный отчёт по позиционированию трейдеров (EURUSD, XAUUSD) в Telegram
Полностью бесплатная схема: GitHub Actions (расписание) + Telegram Bot API.
Что внутри
`sentiment_report.py` — скрипт, который берёт данные и шлёт сообщение в Telegram
`.github/workflows/daily_report.yml` — расписание запуска (по пятницам в 20:30 UTC, сразу после публикации CFTC)
`last_report_date.txt` — служебный файл, создаётся автоматически: хранит дату последнего отправленного отчёта
Шаг 1. Создать Telegram-бота
В Telegram найдите `@BotFather`, отправьте `/newbot`.
Придумайте имя и username бота (username должен заканчиваться на `bot`).
BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохраните его.
Шаг 2. Узнать свой chat_id
Напишите своему новому боту любое сообщение в Telegram (например "привет").
Откройте в браузере:
`https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
В ответе (JSON) найдите `"chat":{"id":XXXXXXXXX` — это ваш `chat_id`.
Шаг 3. Создать репозиторий на GitHub
Зарегистрируйтесь на github.com, если ещё нет аккаунта (бесплатно).
Создайте новый репозиторий, например `forex-sentiment-bot`.
Загрузите туда файлы `sentiment_report.py` и папку `.github/workflows/daily_report.yml`
(через веб-интерфейс "Add file → Upload files", сохранив структуру папок).
Шаг 4. Добавить секреты
В репозитории: Settings → Secrets and variables → Actions → New repository secret
Добавьте два секрета:
`TELEGRAM_BOT_TOKEN` — токен из шага 1
`TELEGRAM_CHAT_ID` — id из шага 2
Шаг 4.5. Разрешить workflow сохранять файл состояния
Скрипт запоминает дату последнего отправленного отчёта в файле
`last_report_date.txt` — это нужно, чтобы не слать повторно тот же отчёт,
если CFTC вдруг задержит публикацию (например, из-за праздника в США).
Workflow сам коммитит этот файл обратно в репозиторий после каждого запуска,
поэтому нужно разрешить Actions запись в репозиторий:
В репозитории откройте Settings → Actions → General.
Прокрутите вниз до раздела Workflow permissions.
Выберите "Read and write permissions".
Нажмите Save.
Без этого шага сам отчёт в Telegram будет приходить нормально, но шаг
"Save last sent state" будет падать с ошибкой доступа при попытке
закоммитить файл.
Шаг 5. Проверить вручную
Перейдите во вкладку Actions репозитория.
Выберите workflow "Weekly CFTC Positioning Report".
Нажмите Run workflow (это возможно благодаря строке `workflow_dispatch` в файле).
Через минуту проверьте Telegram — должно прийти сообщение.
Если сообщение не пришло — откройте лог запуска в Actions и посмотрите на ошибку
(чаще всего это неверный токен/chat_id либо изменившаяся структура страницы-источника).
Шаг 6. Готово
Дальше скрипт будет запускаться автоматически по пятницам в 20:30 UTC —
вскоре после того, как CFTC публикует новые данные. Если новых данных ещё
нет (например, из-за праздника в США), скрипт сам определит это по дате
отчёта и просто пропустит отправку — сообщение придёт при следующем
успешном запуске, как только выйдут новые данные.
Чтобы изменить время или частоту запуска, отредактируйте строку
`cron: '30 20 * * 5'` в файле `.github/workflows/daily_report.yml`
(формат: минута час * * день_недели, время в UTC, 5 = пятница).
Важно понимать про источник данных
Скрипт использует официальный бесплатный API американского регулятора CFTC —
"Commitments of Traders" (данные о позициях крупных трейдеров по фьючерсам
на евро и золото). Это открытые государственные данные без защиты от ботов,
поэтому они надёжно работают из GitHub Actions (в отличие от скрапинга
брокерских сайтов вроде Myfxbook, которые блокируют запросы с серверов).
Важная оговорка: CFTC публикует эти данные раз в неделю (по пятницам,
по состоянию на предыдущий вторник), а не ежедневно. Поэтому в большинстве
дней сообщение будет показывать те же цифры, что и днём ранее — новая дата
"по состоянию на" появится только раз в неделю. Это разумный компромисс для
полностью бесплатного и надёжного решения.
Если CFTC когда-нибудь переименует контракты в датасете, может понадобиться
поправить точные названия рынков (`MARKETS`) в файле `sentiment_report.py` —
в скрипте уже есть запасной вариант поиска по подстроке на этот случай.
Также помните: это позиционирование крупных спекулянтов (не гарантия
направления цены) — используйте как один из контекстных факторов, а не как
самостоятельный сигнал для сделки.
